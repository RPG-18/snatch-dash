# Attribution for the bundled dash-map assets

Everything in this directory is third-party work, shipped inside the APK and
drawn on the dash panel. The dash frame itself carries no attribution: MapLibre's
logo and attribution line are switched off in `MapSnapshotProvider` because at
526×300 under a round bezel they cost a visible share of the frame
(`review-spec.md`, C6). The user-facing credit therefore lives in the **About
card in Settings** (`settingsAboutMapDataTitle` and the links under it) — that
card is not optional decoration, it is what keeps switching the overlay off
legitimate.

| What | Where | Origin | Licence |
|---|---|---|---|
| `styles/positron.json`, `styles/dark-matter.json` | this dir | [openmaptiles/positron-gl-style], [openmaptiles/dark-matter-gl-style] | CC BY 4.0 |
| `sprites/*` | this dir | same style repos, prebuilt sheets | CC BY 4.0 |
| `glyphs/Noto Sans {Regular,Bold}/*.pbf` | this dir | [openmaptiles/fonts] v2.0, `noto-sans.zip` — Noto Sans, patched by Klokan Technologies | SIL Open Font License 1.1 |
| Vector tiles (`*.pmtiles`) | **not here** — `getExternalFilesDir(null)/maps/`, downloaded per region | OpenStreetMap, cut by `tools/planetiler` | ODbL 1.0 (data), CC BY 4.0 (OpenMapTiles schema) |
| MapLibre GL Native | Gradle dependency, not an asset | [maplibre/maplibre-gl-native] | BSD-2-Clause |

The glyph and sprite files are regenerated by `tools/styles/build_styles.py`;
that script downloads them from the upstream repos above, so this table is the
only place recording what those downloads are and under what terms.
