# Offline Maps Screen (Оффлайн-карты)

**Файл:** `lib/screens/offline_maps_screen.dart` (не создан)
**Виджет:** `OfflineMapsScreen` (`ConsumerStatefulWidget`)
**Route:** `/more/offline-maps` — дочерний маршрут ветки «Ещё», открывается с
карточки офлайн-карт в [Настройках](./settings_screen.md) и с карточки на
[Главной](./home_screen.md), когда не скачан ни один пак.

## Назначение

Экран для работы с картами из [интернета](./remote_map_server.md). На этом экране пользователь может:
- поискать доступные карты из интернета
- просматривать скаченные карты
- обновлять карты, если есть новая версия

При открытии этого экрана происходит поиск [index.json](./remote_map_server.md) локально, если нет, то 
скачивает с интернета. Если не может скачать, то выводит текст: "Сервер карт не доступен".

Если локальный index.json существует, то сверяет текущее значение со значением на сервере. То обновляет информацию о новых картах.

**Пока не скачан ни один пак, навигация в приложении заблокирована** — см.
«Связь с навигацией» ниже. Этот экран — единственный способ снять блокировку.

## Читаемое/изменяемое состояние

| Провайдер | Для чего |
|---|---|
| `offlineMapsControllerProvider` | манифест (`index.json`): список доступных паков, `generated_at`, состояние текущих загрузок (прогресс, ошибка) |
| `offlineMapsControllerProvider.notifier` | `refresh()`, `download(code)`, `cancel(code)`, `delete(code)` |
| `installedPacksProvider` | реестр установленных паков (`code`, `sha256`, `generated_at`, размер, время установки), sqlite. Читается также [Главной](./home_screen.md) — гейт навигации |
| `hasInstalledPacksProvider` | `installedPacks.isNotEmpty` — гейт навигации |

Источник истины для секции «Загруженные» — **реестр**, а не список файлов в
каталоге: пак считается установленным только после успешной проверки sha256 и
переименования из `.part` (см. [remote_map_server.md](./remote_map_server.md)).

У движка источник истины **свой и другой** — он перечисляет `maps/*.pmtiles`
при старте стрима и реестра не читает вовсе. Расходиться они не могут: файл
получает имя без `.part` ровно в тот момент, когда попадает в реестр, одним
атомарным переименованием.

## Разметка / действия

Вертикальный лайаут, все карточки расположениы в том же порядке, в каком перечислены.

1. Заголовок `«Оффлайн-карты»`
2. Строка поиска. Плейсхолдер: "иконка лупы" "Поиск городов". При тапе по полу ввода
    открывается на вест экран попап со строкой ввода и списком карт, для скачивания. 
    При наборе текста происходит поиск/фильтрация элементов списка. Эелемент списка
    состоит из: "иконка скачать" название крты (региона, пака тайлов и тд) размер файла.
    При тапе по элементу списка начинается скачивается выбранная карта. Иконка "скачать" меняется на
    иконку "остановить" и круглый прогресс бар вокруг иконки. Тап по элементу списка, когда идет загрузка, вызвает дталог с текстом "Отменить загрузку" с кнопками "Да", "Нет"
3. **Загруженные**:
    - Список загруженных карт. Элемент списка состоит из "иконка карты" название карты(региона, пака тайлов и тд), размер файла, кнопка(три точки) с дополнительными действиаями. Дополнительные
    действия: удалить. Иконка карты меняется на иконку загрузить, если есть новая версия на сервере.
    Логика отмены зазгрузки такая же как в пункте 2.

## Пустые состояния

Три источника данных независимы друг от друга: **реестр установленных паков**
(диск), **локальная копия `index.json`** и **сеть**. Пустым может быть любой из
них по отдельности, и путать их нельзя — «нет сети» и «ничего не скачано» это
разные экраны с разными действиями.

| Ситуация | Что показывает экран |
|---|---|
| Ничего не скачано, манифест получен | Секция «Загруженные» вместо списка: «Нет скачанных карт» и пояснение «Без карт дэш не покажет навигацию». Строка поиска и список доступных карт работают как обычно — это основной сценарий первого запуска |
| Нет локального `index.json`, скачать не удалось | Вместо строки поиска и списка доступных — «Сервер карт не доступен» и кнопка «Повторить». Секция «Загруженные» показывается как обычно, если реестр не пуст: паки лежат на диске и от сети не зависят |
| Локальный `index.json` есть, сеть не ответила | Экран работает целиком по локальной копии, поверх — неблокирующая плашка «Не удалось проверить обновления». Скачивание не запрещаем заранее: тап по элементу пытается качать и падает на общей ошибке загрузки |
| Поиск ничего не нашёл | В попапе под строкой ввода — «Ничего не найдено», список пуст. Строка ввода остаётся активной |

Оба «пустых» текста — про причину, а не про факт: «Нет скачанных карт» без
второй строки не объясняет, почему заблокирована навигация на
[Главной](./home_screen.md).

## Связь с навигацией

Без единого установленного пака дэш физически не может нарисовать карту: кадр
получится пустым фоном стиля, и для райдера это неотличимо от бага рендера
(см. «Режимы отказа» в
[drawing_from_local_tiles.md](./drawing_from_local_tiles.md)). Поэтому вход в
навигацию заблокирован в интерфейсе, а не оставлен «на посмотреть»:

- признак — `hasInstalledPacksProvider`, ровно один на всё приложение;
- блокировка ставится на [Главной](./home_screen.md) — оба входа в навигацию
  (быстрое действие «Начать навигацию» и тапы по сохранённым местам);
- подключение к дэшу **не** блокируется, хотя без паков кадр будет пустым:
  медиа, звонки и сам факт линка от карт не зависят. Экран
  [Dash](./dash_screen.md) в этом случае обязан сказать, что карт нет, —
  иначе пустой кадр читается как поломка;
- блокировка снимается сразу, как только первый пак дошёл до реестра, — без
  перезапуска приложения и без переоткрытия Главной.

### Обратная блокировка: во время навигации карты не трогаем

Зависимость работает и в другую сторону. Смена набора установленных паков
заставляет движок пересобрать стиль, а это **полная** перезагрузка: все
источники сбрасываются и читаются заново, спрайты тоже (см. «Сменить набор
паков = перезагрузить стиль» в
[drawing_from_local_tiles.md](./drawing_from_local_tiles.md)). На ходу такой
перерыв недопустим.

Поэтому пока `navigating == true`:

- **кнопки скачивания и удаления неактивны** — и в списке доступных карт
  (п. 2), и в дополнительных действиях загруженных (п. 3);
- тап по неактивной кнопке показывает **«Выйдите из режима навигации»**
  (`SnackBar`), а не молчит: неактивная кнопка без объяснения читается как
  поломка экрана;
- уже идущая загрузка **не прерывается** — она не меняет набор активных паков,
  пока не дошла до реестра. Блокируется старт новой и удаление существующей;
- признак — `DashEngineState.navigating`, то же поле, по которому [экран
  Dash](./dash_screen.md) показывает кнопку выхода из навигации.

**Блокировка кнопок — не единственная защита, и не главная.** `navigating == false`
не значит «райдер стоит»: ездить без пункта назначения — обычный режим, дэш при
этом рисует карту (состояние `idleMap` в [fsm.md](./fsm.md)), и установка пака в
такой момент дала бы ту же паузу в кадре, только без предупреждения.

Поэтому настоящая гарантия лежит в движке: **набор активных паков читается один
раз при старте стрима**, изменения вступают в силу со следующего подключения
(см. «Сменить набор паков = перезагрузить стиль» в
[drawing_from_local_tiles.md](./drawing_from_local_tiles.md)). Перезагрузка стиля
на ходу так становится невозможной по построению, а не по дисциплине интерфейса.

Блокировка кнопок при этом остаётся, но её роль другая — не техническая, а
объясняющая: без неё райдер скачал бы пак посреди поездки и не понял, почему
карта не изменилась.
