# Expenses Screen (Расходы)

**Файл:** [`lib/screens/expenses_screen.dart`](../lib/screens/expenses_screen.dart)
**Виджет:** `ExpensesScreen` (`ConsumerStatefulWidget`)
**Route:** `/expenses` — вкладка «Расходы» в нижней панели.

## Назначение

Список расходов с фильтрами по категории и месяцу/всему времени, диалог
добавления расхода и экспорт в CSV/HTML через системное меню «Поделиться».

## Читаемое/изменяемое состояние

| Провайдер | Для чего |
|---|---|
| `garageControllerProvider` (`GarageUi`) | список `expenses`, `activeVehicleName` |
| `garageControllerProvider.notifier` | `addExpense`, `deleteExpense` |
| `currencySettingsProvider` (`OpenDashCurrency`) | форматирование суммы/символ валюты (см. [`lib/state/currency_settings.dart`](../lib/state/currency_settings.dart)) |

Локальное состояние виджета: выбранная `_category` (из фиксированного
списка), выбранный `_period` (`_ExpensePeriod` — «Всё время» или один из 12
месяцев текущего года, генерируется лениво под текущую локаль в
`_expensePeriods`).

## Категории: отображение vs хранение

`_categories` (`All Expenses`, `Fuel`, `Repairs`, `Accessories`,
`Riding Gear`, `Food`, `Stay`, `Transport`, `Others`) — это **канонические
английские ключи**, которые хранятся в БД и используются для фильтрации
(`e.category == _category`). Локализуется только отображаемая подпись, через
`_categoryLabel(l10n, category)` — это избавляет от миграции данных и
сохраняет фильтруемость старых записей после смены языка.

## Разметка / действия

1. **Строка заголовка**: сумма по текущему фильтру
   (`formatCurrencyAmount`), `DropdownButton` периода (названия месяцев —
   через `DateFormat.yMMMM(locale)`, без захардкоженных названий), иконка
   экспорта (недоступна, если отфильтрованный список пуст) → нижний лист с
   вариантами «Excel / CSV» / «Документ», каждый делится сгенерированным
   файлом через `share_plus`.
2. **Чипы категорий** — горизонтальный скролл `ChoiceChip`, по одному на
   категорию.
3. **Список расходов** — категория (локализована), заметка либо
   отформатированная дата как подзаголовок, отформатированная сумма +
   иконка удаления в трейлинге.
4. **FAB** → диалог «Добавить расход»: выпадающий список категории, поле
   суммы (с подписью — символом активной валюты), необязательная заметка.

## Заметки

- `_ExpensePeriod.fileLabel` не зависит от локали и состоит из ASCII
  (`yyyy-MM` либо `all-time`) — используется только для имён файлов при
  экспорте, чтобы русское название месяца никогда не попало в путь файла.
- Заголовки/содержимое экспорта (`ExpenseExporter`) намеренно остаются на
  английском — это файлы с данными, а не элементы интерфейса, они не
  входили в объём RU/EN-локализации.
