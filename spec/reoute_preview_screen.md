# Preview Routes Screen ("Маршруты")

**Файл:** [`lib/screens/route_preview_screen.dart`](../lib/screens/route_preview_screen.dart)
**Виджет:** `RoutePreviewScreen` (`StatelessWidget`)
**Route:** `/home/route-preview` — открывается с экрана «Маршрут» после выбора
найденного места, или с Главной при тапе на сохранённое место.

## Назначение 

Выбор из нескольких марштрутов от текущей точни до пункта назначения. Маршруты строятся через Yandex MapKit.

## Разметка / действия

- Заколовок экрана "Маршруты"
- Вертикальный лайаут
- 75%  экрана отведена под карту yandex, на которой рисуются маршруты
- В горизонтальном списке отображаются карточки с маршрутом
- Завершает вертикальный лайаут кнопка "Поехали"
- Зум карты автоматически подбирается, что бы все маршруты помещялись. С отступами до 8% с каждой из сторон.
- Маршруты можно переключать через картички маршрута и по пару по маршруту на карте. Состояние синхронизиируется, подсвечивается соответсвующая карточка.

Картачка марштура состоит:
- Вертикальный лайаут
- Время маршрута(жирный шрифт)
- Длина(расчитанный yandex, а не растояние по прямой между двумя точками)

Выбранный пользователем маршрут рисуется с [параметрами рисования](./yande_ruote.md) с учетом дорожной ситуации, остальные маршруты фолетовые. По умолчанию выбран быстрый маршрут(не короткий)
