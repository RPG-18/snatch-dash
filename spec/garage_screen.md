# Garage Screen (Гараж)

**Файл:** [`lib/screens/garage_screen.dart`](../lib/screens/garage_screen.dart)
**Виджет:** `GarageScreen` (`ConsumerStatefulWidget`,
`SingleTickerProviderStateMixin` для `TabController`)
**Route:** `/garage` — вкладка «Гараж» в нижней панели.

## Назначение

Учёт пробега, журнал заправок и отслеживание интервалов обслуживания для
активной техники, на двух вкладках.

## Читаемое/изменяемое состояние

| Провайдер | Для чего |
|---|---|
| `garageControllerProvider` (`GarageUi`) | `odometerKm`, `fuel` (список с `kmpl` по каждой заправке), `avgKmpl30`, `fills30`, `litres30`, `maint` (список с `tone`/`remainingKm`) |
| `garageControllerProvider.notifier` | `setOdometer`, `addFuel`, `deleteFuel`, `addService`, `markServiceDone`, `deleteService` |

## Разметка / действия

- **AppBar**: заголовок `«Гараж · {odometerKm} км»`; `TabBar` (Топливо /
  Обслуживание); иконка спидометра → диалог задания пробега.
- **FAB**: на вкладке «Топливо» открывает диалог «Добавить заправку», на
  вкладке «Обслуживание» — «Добавить интервал» (какой именно — определяет
  `_tabs.index`).

### Вкладка «Топливо» (`_FuelTab`)

- Пустое состояние: «Заправок пока нет».
- Строка статистики: средний расход за 30 дней (км/л), число заправок за
  30 дней, литров за 30 дней.
- Список заправок: литры · стоимость, затем `{odometerKm} км` (+
  `· {kmpl} км/л`, если можно посчитать), иконка удаления в каждой строке.

### Вкладка «Обслуживание» (`_MaintenanceTab`)

- Пустое состояние: «Интервалов обслуживания пока нет».
- По карточке на интервал: иконка (по `iconKey`: chain/drop/gauge/
  thermo/fuel/build), окрашенная по `tone` (`alert`→цвет ошибки,
  `warn`→жёлтый, иначе зелёный); название; «Осталось {km} км» либо
  «просрочено на {km} км»; всплывающее меню («Отметить выполненным
  сегодня» / «Удалить»).

## Диалоги

- **Задать пробег** — одно числовое поле (км).
- **Добавить заправку** — литры, стоимость, пробег (км), место
  (необязательно).
- **Добавить интервал** — название, интервал (км, по умолчанию `1000`).

Все три диалога используют общие ключи локализации `actionCancel`/`actionSave`.

## Заметки

- Формулировка «осталось» (`dashDistanceRemaining`, например «Осталось 42
  км») — общий ключ локализации с чипом оставшегося расстояния на экране
  Dash: тот же текст, другой экран.
