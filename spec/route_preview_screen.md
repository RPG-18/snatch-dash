# Preview Routes Screen ("Маршруты")

**Файл:** [`lib/screens/route_preview_screen.dart`](../lib/screens/route_preview_screen.dart)
**Виджет:** `RoutePreviewScreen` (`StatelessWidget`)
**Route:** `/home/route-preview` — открывается с экрана «Маршрут» после выбора
найденного места, или с Главной при тапе на сохранённое место.

## Назначение

Выбор из нескольких маршрутов от текущей точки до пункта назначения. Маршруты строятся через Yandex MapKit.

## Разметка / действия

- Заголовок экрана "Маршруты"
- Вертикальный лайаут
- 75% экрана отведено под карту Yandex, на которой рисуются маршруты
- В горизонтальном списке отображаются карточки с маршрутом
- Завершает вертикальный лайаут кнопка "Поехали"
- Зум карты автоматически подбирается, чтобы все маршруты помещались. С отступами до 8% с каждой из сторон.
- Маршруты можно переключать через карточки маршрута и по тапу по маршруту на карте. Состояние синхронизируется, подсвечивается соответствующая карточка.

Карточка маршрута состоит:
- Вертикальный лайаут
- Время маршрута (жирный шрифт)
- Длина (рассчитанная Yandex, а не расстояние по прямой между двумя точками)

Выбранный пользователем маршрут рисуется с [параметрами рисования](./yande_ruote.md) с учётом дорожной ситуации, остальные маршруты фиолетовые. По умолчанию выбран быстрый маршрут (не короткий)
