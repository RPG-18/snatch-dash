# Vehicles Screen (Техника)

**Файл:** [`lib/screens/vehicles_screen.dart`](../lib/screens/vehicles_screen.dart)
**Виджет:** `VehiclesScreen` (`ConsumerWidget`)
**Route:** `/vehicles` — вкладка «Техника» в нижней панели.

## Назначение

Управление профилями техники: список всей техники, отметка активной,
добавление/редактирование профилей (данные техосмотра/страховки/ТО).

## Читаемое/изменяемое состояние

| Провайдер | Для чего |
|---|---|
| `vehicleStoreProvider` (`VehicleState`) | список `vehicles`, `activeVehicleId` |
| `vehicleStoreProvider.notifier` | `select`, `add`, `update` |

## Разметка / действия

1. **Список техники** (`_VehicleTile` на каждую запись): название,
   прозвище (если есть), `_MetaRow` для Техосмотра / Страховки / ТО
   (подсвечиваются красным, если значение `expired` или `na`, без учёта
   регистра), затем либо `Chip` «Текущая техника» (если активна), либо
   кнопка «Сделать текущей», плюс иконка редактирования.
2. **Кнопка «Добавить технику»** внизу → открывает диалог редактирования с
   пустыми полями/`«Не задано»` и `isNew: true`.
3. **Диалог редактирования** (`_EditVehicleDialog`): текстовые поля —
   название техники, прозвище, срок техосмотра (`ДД-МММ-ГГГГ`), срок
   страховки (`ДД-МММ-ГГГГ`), ТО. Кнопка «Сохранить» недоступна, пока
   название пустое; пустые необязательные поля сохраняются как строка-
   заглушка `«Not set»`.

## Заметки

- Поля `puc`/`insurance`/`service` хранят в данных буквальную английскую
  заглушку `"Not set"` (см. конструирование `VehicleProfile` в этом файле и
  в дефолтной технике в
  [`lib/state/vehicle_store.dart`](../lib/state/vehicle_store.dart)) —
  **локализуется только отображаемый текст**, через
  `_displayValue(l10n, value)` в `_VehicleTile`, чтобы не потребовалась
  миграция уже сохранённых профилей.
