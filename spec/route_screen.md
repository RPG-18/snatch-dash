# Route Screen (Маршрут)

**Файл:** [`lib/screens/route_screen.dart`](../lib/screens/route_screen.dart)
**Виджет:** `RouteScreen` (`ConsumerStatefulWidget`)
**Route:** `/home/route` — открывается с тайла «Начать навигацию» на Главной
или при тапе на сохранённое место.

## Назначение

Поиск места назначения через Yandex Maps Suggest API. В поле ввода осуществляется ввод места назначения. При вводе от 3-х символов осуществляется текстовый поиск назначения и выводится до 10 найденных элементов.

Список автоматически обновляется при редактировании строки поиска.

После выбора пункта назначения открывается экран "Превью Маршрутов" с указанием текущей координаты и выбранной.


## Разметка / действия

Используется стек, чтобы не плодить экраны и переходы между экранами.

### Начальное состояние

1. **Строка ввода**: (подсказка — `Куда`).
2. **Список найденных мест**: элемент списка состоит из двух частей — название жирным шрифтом, снизу адрес обычным шрифтом. В правом верхнем углу отображается расстояние до объекта.
3. После выбора элемента происходит переход стека в режим просмотра пункта назначения.

### Просмотр пункта назначения

1. Открыта yandex карта, на которой отображается пункт назначения
2. Карточка с описанием пункта назначения.
3. Внизу карточки описания горизонтально расположены кнопки: "Маршрут", кнопка с иконкой закладки.
4. В правом верхнем углу карточки с описанием расположена иконка крестика закрыть.

- если нажать на крестик, то лайаут возвращается в **начальное состояние**
- если нажать на кнопку "Маршрут" то происходит переход на экран [Маршруты](./route_preview_screen.md)
- если нажата кнопка закладки, то пункт назначения сохраняется в базе и отображается на [главной](./home_screen.md) в **Сохранённые места**

## Заметки

- **Пункт назначения попадает в приложение только отсюда и из сохранённых
  мест.** Шара из Google Maps (`ACTION_SEND` с `text/plain`, `geo:`,
  `maps.google.com`/`goo.gl`), которая была в оригинальном open-dash, из порта
  убрана целиком — вместе с интент-фильтрами в манифесте, `LocationParser` и
  `RouteController.setDestinationFromShareText`. Это не «не доделано»: любой
  внешний вход открывал бы навигацию мимо [Главной](./home_screen.md), то есть
  мимо проверки на скачанные офлайн-карты (см.
  [оффлайн-карты](./offline_maps_screen.md), «Связь с навигацией»).
- Живой список подсказок идёт через HTTP Yandex Geosuggest API
  (`api/openapi/yandex-suggest-api.yaml`, реализация — [`lib/nav/suggest_api.dart`](../lib/nav/suggest_api.dart)),
  а не через MapKit `SearchManager`. Ключ передаётся через
  `--dart-define-from-file` как `YANDEX_API_KEY` (см.
  `android/dart_defines.local.properties` / `dart_defines.defaults.properties`) —
  единый ключ на все продукты Yandex, тот же, что и для MapKit в `lib/main.dart`.
- Защита от лишних запросов к Suggest API (`lib/state/route_search_controller.dart`):
  debounce 300мс + минимум 3 символа перед первым запросом, отмена ещё летящего
  запроса при новом keystroke через `AbortableRequest` (`package:http` ≥1.6),
  и LRU-кэш последних 16 нормализованных запросов, чтобы бэкспейс/повтор
  ввода не бил в сеть повторно.
- Suggest API не возвращает координаты — это только текстовые подсказки.
  При выборе элемента `RouteSearchController.resolve` делает полноценный
  поиск через MapKit `SearchManager` (`PlaceSearch.search`, `resultPageSize: 10`,
  без ограничения одним результатом) по тексту подсказки, т.к. одному имени
  может соответствовать несколько разных организаций (например, сеть
  магазинов) — в этом случае перед переходом на "Превью Маршрутов"
  показывается bottom sheet с уточнением, какое именно место имелось в виду.
  Примеры запросов к `SearchManager` — https://github.com/yandex/mapkit-flutter-demo/tree/master/mapkit-samples/map_search
